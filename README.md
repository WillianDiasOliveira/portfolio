# Portfolio — Willian Dias de Oliveira

Projeto Vite + React standalone com a página de portfolio.

## Como rodar localmente
```bash
npm install
npm run dev
```
Abre em http://localhost:8080

## Build para produção
```bash
npm run build
```
Os arquivos finais ficam em `dist/`. É só hospedar essa pasta em qualquer servidor estático (Vercel, Netlify, GitHub Pages, Cloudflare Pages, etc.).
